# ВКУСНО. и точка — сборка APK с телефона

## Что делать
1. Создай репозиторий GitHub.
2. Загрузи содержимое этой папки в репозиторий (можно через ZIP/Files).
3. Открой вкладку **Actions**.
4. Выбери **Build APK**.
5. Нажми **Run workflow**.
6. После завершения открой запуск workflow и скачай artifact `vkusno-game-apk`.
7. Внутри будет `app-debug.apk`.

Сборка выполняется на серверах GitHub, поэтому Android Studio на телефоне не нужна.
